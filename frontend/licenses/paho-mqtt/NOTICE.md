also includes the complete EDL notice for distribution with embedded images.

`src/hubPaho.js` is generated by `node tools/generate-hub-paho.mjs` from the pinned
upstream file, whose SHA-256 is
`a0c734a00a2172d579ca1ff4f92fb366bccb40974005bdad5ea7a2f0326ac158`.
The generator verifies that hash and every unique replacement point. It changes
the module boundary to a per-connection ESM factory and adds an abort hook to
close a connecting WebSocket and cancel Paho's timers. MQTT protocol encoding,
decoding and acknowledgement handling remain the upstream implementation.

Check reproducibility with `node tools/generate-hub-paho.mjs --check` after
`npm ci`. The hub adapter uses isolated, bounded memory storage; it does not
persist pending commands into browser localStorage.
